CSS 기초 연습 사이트

- 파일 위치:
  - index.html
  - styles.css

사용 방법:
1. 폴더를 파일 탐색기에서 열고 `index.html`을 더블클릭하여 브라우저로 엽니다.
2. HTML 구조를 수정하거나 `styles.css`의 값을 바꿔 실험하세요.
3. 연습 제안: 색, padding, margin, border, flex 속성, :hover 효과를 바꿔 결과를 확인하세요.

학습 목표:
- 요소/클래스/아이디 선택자 이해
- 박스 모델(padding, border, margin, box-sizing)
- 간단한 Flexbox 레이아웃
- 호버와 전환, 반응형 미디어쿼리 실습
